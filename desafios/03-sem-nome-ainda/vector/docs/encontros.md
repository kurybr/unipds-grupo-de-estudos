# Encontros do grupo de estudos UNIPDS

O grupo é uma iniciativa independente de alunos da 1ª turma de Engenharia de Software em IA Aplicada da UNIPDS. Não tem vínculo oficial com a instituição.

## Laboratório prático

O laboratório acontece às terças-feiras, às 19h30, na sala virtual chamada Vetorial.
O código de presença deste mês é PDS-19.
Quem chega depois das 19h45 registra presença com o código PDS-19-ATRASO.

No laboratório a turma escolhe um tema e implementa junto, do requisito até o código.

## Mesa de ajuda

A mesa de ajuda é o espaço para dúvidas trazidas pelos participantes ao longo do mês.
A prioridade dos assuntos é definida pela comunidade, não por uma pauta fixa.

## Casos reais

O encontro de casos reais olha arquitetura de produtos do mercado.
Vale especular como uma solução pode ter sido construída, desde que a hipótese fique explícita.

## Showcase

O showcase é o último encontro do mês.
Cada pessoa pode mostrar projeto pessoal, MVP, protótipo ou experimento.
O feedback esperado é de arquitetura e de próximos passos, não uma nota.

## Organização

O planejamento do grupo fica no GitHub Projects do kurybr, projeto número 2.
O repositório centraliza desafios, materiais e anotações dos encontros.
